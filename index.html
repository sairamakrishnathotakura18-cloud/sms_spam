ARCHITECTURE & STACK

Powered by Machine Learning

Our intelligent pipeline combines natural language processing algorithms with robust REST API serving.

TF-IDF Vectorization

Converts raw SMS text into numeric feature matrices using Term Frequency-Inverse Document Frequency n-grams.

Multinomial Naive Bayes

Applies Bayes' Theorem to calculate the posterior probability of a text message being spam based on word occurrences.

Python + Flask API

High-performance RESTful API endpoints serving real-time predictions, metrics, and batch processing.

Scikit-Learn Library

Industry-standard machine learning toolkit used for preprocessing, training, and model evaluation.
